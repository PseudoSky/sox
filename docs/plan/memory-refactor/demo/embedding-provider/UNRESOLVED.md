## Scope gaps & open questions

- **Package not yet built.** This DEMO.md is the acceptance contract for a package that does not yet exist on npm. The `npm install @adhd/sox-embedding-provider` step in §2.4 will only work after the package is published (or via `npm pack` + local install during development). The demo should be re-run against the real package to validate all ⟦U1⟧–⟦U6⟧ stubs before treating any beat as authoritative.

- **REQ-005 startup cache.** USE_CASES.md UC-EMB-5 calls for "a startup Map cache for hot/topic embeddings." SCOPE.md Part D mentions "Optional `queryEmbed` (query-optimized) + a startup Map cache." No API name, signature, or factory is described in SCOPE.md, USE_CASES.md, or `pack-smoke.mjs`. Beat 1.1 covers the latency-sensitive single-embed path, satisfying the first half of REQ-005, but the cache API (e.g., a `warmCache(texts)` call or similar) has no grounding and is not demonstrated. Once the API is defined, add a beat to Act 3 showing cache warm-up and a repeated embed confirming the cache hit.
