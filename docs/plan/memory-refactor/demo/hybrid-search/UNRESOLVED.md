## Scope gaps & open questions

1. **Package not built yet.** `@adhd/sox-hybrid-search` (and its public peers `@adhd/sox-graph-store`, `@adhd/sox-vector-store`) do not exist in npm as of 2026-06-26 — this DEMO.md is the implementation acceptance contract, authored against the design spec (`docs/plan/memory-refactor/contexts/w2d-hybrid-search.md`) and SCOPE Part D. The install beat (§2.4) assumes all three packages are published to the public npm registry. All beats are speculative until the packages are built and published.

2. **REQ-010 runtime observability.** The `bm25(col_weights)` single-FTS5-query requirement (w2d-hs.6) is verified by code inspection + vitest per the acceptance criteria, not by a runtime-observable signal in this demo. The beats that exercise BM25 (§4.1 degrade path, climax) prove that BM25 results are returned and are non-empty, but do not assert the internal SQL shape. A supplementary code-inspection step or a test that counts FTS queries per call is needed to fully verify w2d-hs.6.
