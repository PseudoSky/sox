# Changelog

## 0.1.2

- Converted to the cross-platform `agent`/`render.<host>` IR pattern (matching `dispatcher` and `researcher`): `architect.md` is prose-only (frontmatter stripped), and the per-host header is generated by `libs/host-registry/src/agent-renderers.ts` at install time from `extension.json`.
- Logical model tier: `sonnet` (deepseek/deepseek-flash in opencode render, mapped to sonnet tier in IR).
- NOTE: `steps: 100` field in prior frontmatter has no IR slot and is not preserved — architect does not reference this field at runtime.

  Flash id no longer resolves on the `deepseek` provider, so the pinned agent failed at dispatch
  time with "Model not found").

## 0.1.0
