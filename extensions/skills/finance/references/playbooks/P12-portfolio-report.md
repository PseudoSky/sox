# P12 portfolio-report

Stage: report. Terminal. Reads: P0 receipts, the plan index, the account config, and optionally P2, P4, P9 receipts. Emits: `.finance/reports/<as_of>.md` and `.json`.

`report --as-of <date>` recomputes the analysis through the same code path as P0, writes receipts, and renders. Sections: executive summary, holdings overview (with cost basis and unrealized P&L from the broker's average cost), allocation (cash is its own bucket, so types sum to 100%), risk, market posture, income, recommendations, active plans, action items (from warnings, plans expiring within 3 days, and any non-cash position above 25% of equity), appendix with receipt paths. The posture, income and recommendations sections render the latest receipts from `market posture`, `analyze --income --write` and `recommend`; a missing receipt is stated with the command that creates it. `report` covers every account; `report --account <id>` limits it to one. A recommendation receipt older than the latest paper fill is marked STALE with the command that refreshes it. Realized P&L of paper sales is listed under Holdings. No number is typed by hand.
`--as-of` pins the valuation date and is optional (default: the newest account date). Snapshot age is always measured against today's date, so a report of an old snapshot warns even when `--as-of` is that snapshot's date. A posture receipt carries its own date; when it differs from the valuation date, both are shown.
