## Corrections to initial assumptions (Phase 0 priors vs evidence)
- **PREMISE WRONG on the PR number:** the format rewrite is **PR #8517** ("replace the transactional
  manifest with a segment registry", merged 2026-08-31), **not #8085** (#8085 is an earlier FTS
  *performance* PR). The premise conflated them.
- **PREMISE IMPRECISE on "breaking on-disk format change":** the SQLite *container/page* format is
  unchanged (FTS lives in ordinary btrees inside a normal `SQLite format 3` file). The break is a
  *schema/content* change in the internal FTS backing-table row layout, and it is **gated behind the
  still-required `--experimental-index-method` flag**.
- 0.8.0 is marketed upstream as a *performance* release (group commit), not a format-break release —
  the format change is a quiet, flag-gated consequence inside the FTS feature.
